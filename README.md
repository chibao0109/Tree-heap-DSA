# 🌳 Data Structures and Algorithms — Trees & Heaps

Welcome to **DSAGIT**, a repository for learning and practicing fundamental data structures and algorithms, with a focus on **Trees and Heaps**.

This project explores how hierarchical data is organized, how tree-based structures work, and how heap operations maintain ordering efficiently.

## 📚 Topics Covered

### 1. Trees
- Tree terminology: root, parent, child, leaf, depth, and height
- Binary Trees
- Binary Search Trees (BST)
- Tree traversal: preorder, inorder, postorder, and level-order
- Searching, insertion, and deletion in trees

### 2. Heaps
- Heap properties and structure
- Min-Heap and Max-Heap
- Array-based heap representation
- Insertion using heapify-up
- Deletion using heapify-down
- Building a heap from an array
- Heap operations and time complexity

## 🎯 Learning Objectives

- Understand the fundamental concepts of Trees and Heaps.
- Implement and analyze common data structure operations.
- Understand how algorithms maintain structural properties.
- Practice problem-solving and algorithmic thinking.
- Analyze time and space complexity using Big-O notation.

## ⏱️ Time Complexity

| Operation | Binary Search Tree* | Binary Heap |
|---|---|---|
| Search | O(log n) average | O(n) |
| Insert | O(log n) average | O(log n) |
| Find minimum | O(log n) average | O(1) for Min-Heap |
| Find maximum | O(log n) average | O(1) for Max-Heap |
| Remove root / top | Depends on implementation | O(log n) |

\*The average BST complexities assume reasonably balanced trees. An unbalanced BST can require O(n) time for search, insertion, or deletion.
